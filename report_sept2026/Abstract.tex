\textbf{{\Large ABSTRACT}}\\
\begin{center}
\justifying
Linear recurrent neural networks are an efficient alternative to attention for long sequences, but their ability to track state depends on the structure of their state-transition matrix. DeltaProduct builds this matrix as a product of $n_h$ generalized Householder factors, where $n_h$ is fixed by hand and applied to every token, so every token pays for the most demanding one. This project determines how many factors each token requires and makes that number per-token and learned.

After reproducing DeltaProduct on the $S_3$ and $S_5$ word problems, we show by explicit construction that the number of factors a token requires is set by the cheapest faithful representation of the group generated by the whole input alphabet, not by the token alone: a 5-cycle needs four factors when the alphabet generates $S_5$ but only two when it generates $A_5$. With an allocation derived from this analysis, per-token order matches the accuracy of the four-factor model at 1.15 to 1.75 factors per token. A monotone halting gate trained end to end with a compute-budget penalty recovers this structure without supervision in 3 of 10 runs, at 2.20 factors per token and a token accuracy of 0.9998. On natural-language entity tracking (the Boxes dataset), a DeltaProduct layer reaches 0.968 exact match after one state update, against 0.312 for attention of the same size. The savings reported are in required factors per token; realising them in time is the main direction for future work.
\end{center}
